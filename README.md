# Farm

重度障害のある利用者を含む、幅広い人が自分のペースで楽しめるインタラクティブアプリ・ゲームの開発プロジェクトです。SERAとは独立しています。

## 方針
- タップとドラッグを中心とし、直感的な操作を優先する。
- 感覚的な体験だけでなく、反復作業と明確な達成・終了のあるタスクを提供する。
- 古いAndroidタブレットでも利用しやすいよう、単体HTML・CSS・JavaScriptを基本とする。外部依存・通信・インストールを不要にする。
- 個人情報や利用者の記録を公開リポジトリに保存しない。

## ゲーム
- [貨物梱包ゲーム](games/packing/index.html)：疑似3Dの梱包と出荷。HTMLを保存しブラウザで開く。

# Farm 初期仕様

## プロジェクト
古い Android タブレットを想定した軽量インタラクティブアプリ。反復作業を楽しみたい利用者にも対応し、タスクに明確な終了を設ける。

## 貨物梱包ゲーム v0.1
- 工業的な貨物、コンテナ、運搬車を CSS の疑似3Dで表現する。
- 荷物をドラッグして作業台のコンテナに入れる。
- 梱包方式はランダムに3種類：蓋を閉じる、2本のバンドを留める、保護カバーを閉じる。
- 梱包完了した荷物は右側の積載エリアに自動で積まれる。
- 最大積載（試作では4個）になったら、積荷全体を運搬車にドラッグして出荷する。
- 出荷でクリア。再プレイは明示的なボタンで開始する。
- ドラッグが難しい場合は、対象をタップしてから移動先をタップする代替操作も用意する。
- 制限時間なし。間違った場所へのドロップは元に戻る。スコアや罰は設けない。

## 技術
単体 HTML、CSS、通常の JavaScript。外部ライブラリ、画像素材、インターネット接続、WebGL 不要。横画面優先、縦画面でも操作可能なレスポンシブ構成。実機のブラウザバージョン・画面解像度・操作性は検証が必要。

## 検証項目
初期表示、3方式の梱包、誤ドロップ、4個までの積載、満載前の出荷防止、出荷と終了、再プレイ、タップ代替操作、低性能端末での滑らかさ。

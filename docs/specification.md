# Farm 初期仕様

## プロジェクト
古い Android タブレットを想定した軽量インタラクティブアプリ。反復作業を楽しみたい利用者にも対応し、タスクに明確な終了を設ける。

## 貨物梱包ゲーム v0.1
- 工業的な貨物、コンテナ、運搬車を CSS の疑似3Dで表現する。
- 荷物をドラッグして作業台のコンテナに入れる。
- 梱包方式はランダムに3種類：蓋を閉じる、2本のバンドを留める、保護カバーを閉じる。
- 梱包完了した荷物は右側の積載エリアに自動で積まれる。
- 最大積載（試作では4個）になったら、積荷全体を運搬車にドラッグして出荷する。
- 出荷でクリア。再プレイは明示的なボタンで開始する。
- ドラッグが難しい場合は、対象をタップしてから移動先をタップする代替操作も用意する。
- 制限時間なし。間違った場所へのドロップは元に戻る。スコアや罰は設けない。

## 技術
単体 HTML、CSS、通常の JavaScript。外部ライブラリ、画像素材、インターネット接続、WebGL 不要。横画面優先、縦画面でも操作可能なレスポンシブ構成。実機のブラウザバージョン・画面解像度・操作性は検証が必要。

## 検証項目
初期表示、3方式の梱包、誤ドロップ、4個までの積載、満載前の出荷防止、出荷と終了、再プレイ、タップ代替操作、低性能端末での滑らかさ。

## POWER STATION v0.1
- 巨大なスイッチを含むパネル全体をタップ可能にする。電源、冷却、駆動、発進の4工程を各3回、計12回操作する。
- 工程ごとの高彩度色、押下アニメーション、12段階の進捗表示、工程別の短い合成効果音、完了音を用意する。
- Web Audio APIによる音声合成。初期音量は小、消音・小・中・大の4段階を選択できる。連続入力時は前の音を停止し、音が重なり続けないようにする。音声非対応でも進行可能。
- 時間制限、失敗、減点、点滅なし。終了画面と明示的な再プレイ。個人情報の取得や保存なし。
- 単体HTML、外部依存なし。縦横画面に対応する設計。実機でのタッチ操作、音量、Web Audio対応は未検証。

## WALL SMASH v0.1（試作）
- 画面の大きな操作領域のタップで左右交互のパンチ。入力を予約し、壁の12ブロックを順に破壊したらクリア。時間制限・失敗なし、明示的な再プレイあり。
- 人物はモデスタ入力形式の37ノード・設計上1320三角形（面取り前）をHTMLに内蔵。閉じた断面形状、階層付き肩・肘ピボット、面単位の陰影。Canvas 2D上で3D頂点を投影・深度整列するためWebGL不要。手足は剛体パーツでスキニングなし。別添 model.modesta.json はモデスタCLI向け設計草案。Blenderによる生成・GLB出力・実画像審査は未実施。HTMLの描画は独立した暫定実装であり、モデスタ生成GLBではない。
- 破片・粉塵は寿命付き、アイドル時の連続描画なし。音量4段階、初期小。動き軽減設定では破片・粉塵を抑止。音声未対応でも操作可能。
- 破壊は物理シミュレーションでなく演出。打撃位置近くからブロックを選択し、残りは壁全体の破壊として扱う。ブラウザ・Android実機での描画、接触、音量、FPSは未検証。
